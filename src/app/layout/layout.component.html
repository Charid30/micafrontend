Activez les notifications

Les notifications sont obligatoires pour utiliser la plateforme. Vous serez prévenu quand le rapport hebdomadaire est prêt et, le soir, quand une saisie du jour dont vous avez la charge n'est pas faite.

Cliquez sur le bouton puis choisissez « Autoriser » dans la fenêtre du navigateur.

Les notifications sont bloquées pour ce site.

  1. Cliquez sur l'icône du cadenas à gauche de l'adresse du site.
  2. À « Notifications », choisissez « Autoriser ».
  3. Cliquez sur « Vérifier à nouveau » (ou rechargez la page).
